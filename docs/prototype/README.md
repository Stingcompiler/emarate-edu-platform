## كيف تراجعه
1. افتح الرابط على الهاتف، اضغط «تشغيل» على شاشة «القائمة» وانتقل بالروابط (الشريط السفلي، الصفوف، الأزرار).
2. الشاشات ذات الأزرار الفعلية: المادة (المقاطع)، الواجب (Sheet التسليم)، الاختبار (الاختيارات وشبكة الأسئلة).
3. سجّل ملاحظاتك في `feedback.md` (أو كتعليقات على الشاشة نفسها في الصفحة).

## ملاحظات
- البيانات كلها تجريبية على نمط الجامعات السودانية.
- الأيقونة في الشاشات تمثيل مبسّط للشعار (ذرّة + صقر) وتُستبدل بالشعار الرسمي المحسّن لاحقًا.
- `screens/` تحوي مصدر كل شاشة (`.dc.html`) و`canvas.json` كما نُشرت؛ هذه الملفات تُعرض بشكل صحيح داخل صفحة النموذج فقط.
