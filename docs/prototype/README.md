## كيف تراجعه
1. افتح الرابط على الهاتف، اضغط «تشغيل» على شاشة «القائمة» وانتقل بالروابط (الشريط السفلي، الصفوف، الأزرار). كل الروابط بين الشاشات تعمل (80/80 بلا روابط مكسورة).
2. الشاشات ذات الأزرار الفعلية: المادة (المقاطع)، الواجب (Sheet التسليم)، الاختبار (الاختيارات وشبكة الأسئلة)، اللوائح (إقرار الاطلاع).
3. شاشات سطح المكتب تُراجع من الحاسوب؛ الهاتف يعرضها مصغّرة.
4. سجّل ملاحظاتك في `feedback.md` (أو كتعليقات على الشاشة نفسها في الصفحة).

## ملاحظات
- البيانات كلها تجريبية على نمط الجامعات السودانية.
- الأيقونة في الشاشات تمثيل مبسّط للشعار (ذرّة + صقر) وتُستبدل بالشعار الرسمي المحسّن لاحقًا.
- `screens/` تحوي مصدر كل شاشة (`.dc.html`) و`canvas.json` كما نُشرت؛ هذه الملفات تُعرض بشكل صحيح داخل صفحة النموذج فقط.
- لوحة مدير القسم على سطح المكتب تحافظ على آلية العمل الحالية (D-workflow): جدول المواد ← تعيين أستاذ/معيد ← اعتماد طلبات التسجيل، بلا خطوات إضافية.
