## الكتابات وسجل التدقيق

كل سطر أُضيف منذ `c8479a8` فيه كتابة (`save`، `delete`، `create`، `update`، `bulk_*`) خارج الاختبارات
والترحيلات قُرئ: كلها داخل خدمات تكتب سجل تدقيق في المعاملة نفسها (`accounts/services.py`،
`content/staff.py`، `content/deletions.py`، `organization/services.py`، `students/promotion.py`)،
أو في عرض يسجّل مباشرة بعدها (`notifications/views.py` الإخفاء الناعم، `admissions/views.py` حذف
الدورة). **لا كتابة بلا تدقيق.**
