## 3. R73 — الواجهة تعرض حذفًا يرفضه الخادم (🟠)

مشرف النظام يملك ما يملكه المدير عدا الحذف، والخادم يرفض له كل DELETE. الصفحات التالية كانت تعرض له
زر الحذف:

| الصفحة | ما كان يحدث | الإصلاح |
|---|---|---|
| `/site/redirects` | الزر ظاهر؛ الرفض **يُبتلع بصمت** (لا يُفحص الرد) — يبدو كأن شيئًا لم يُضغط | الزر يُخفى، والرفض يُعرض |
| `/site/media` | الزر ظاهر؛ الرفض يُبتلع — ومعه **409 «الصورة مستعملة»** لمدير الموقع نفسه | الزر يُخفى، والرفض يُعرض |
| `/system/structure` | «حذف البرنامج»، «حذف القسم»، «دمج» ظاهرة، ثم 403 | تُخفى، ونص «دمج القسم وحذفه لمدير النظام» |
| `/result-imports/:id` | «إلغاء الدفعة» ظاهر لمشرف النظام ومشرف القسم، ثم 403 | يُخفى بلا `results.delete` |

الآلية: `/api/v1/me` يعيد `deletes` (القدرات التي يُقبل منها DELETE لهذا المستخدم)، و`canDelete(me, cap)`
في `lib/nav.ts`. اختبارات: `test_me_says_what_each_role_may_delete`، `test_roles_add_up_on_a_delete`،
و`e2e/tests/journeys.spec.ts` «the system supervisor sees no delete or merge in the structure».

**لم يُفحص:** بقية الصفحات التي فيها حذف وتستعمل قدرة حذف صريحة (`courses.delete`، `learning.delete`،
`students.delete`، `users.delete`) — قُرئت شروطها ولم تُجرَّب في المتصفح بحساب المشرف.
