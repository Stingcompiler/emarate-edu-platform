## R92 🟡 — الدخول إلى البوابة يتجاوز حد LCP على 3G سريع

أكبر عنصر في الصفحة هو العنوان «مرحبًا بك في بوابة الكلية»، وترسمه الواجهة بعد أن يصل:

| ما يُنتظر | الحجم |
|---|---|
| JavaScript (`index` 95 KB + `ui` 59 KB) | 154 KB |
| الخطوط: IBM Plex Arabic بثلاثة أوزان (400، 600، 700) × مجموعتي العربية واللاتينية | **188 KB** |
| الشعار بصيغته الأصلية (`…/1000243715.jpg`) | 41 KB |
| CSS | 26 KB |

- **الخطوط:** docs/09 يقول «وزنان في التحميل الأول»، والدخول يحمّل ثلاثة. توحيد `font-semibold` و`font-bold` في
  وزن واحد في الصفحات الأولى يوفّر نحو 65 KB. وهذا قرار تصميم.
- **الشعار:** الموقع يقدّم الشعار مصغّرًا بصيغة WebP (`site-logo.webp`، مراجعة التصميم B6)، والبوابة تأخذ الملف
  الأصلي من `logo_url`. أيقونة التطبيق (`portal-icon/192.png`) لا تصلح بديلًا لأنها تُرسم بخلفية وهامش. والحل
  نقطة تقدّم الشعار مصغّرًا كما يفعل الموقع.
- **JavaScript:** في الحد (148.5 kB مضغوطًا من 200 kB، `language/README.md`).

لم يُصلح في هذه الجولة: الأول قرار تصميم، والثاني نقطة API جديدة. وهما في قائمة المالك.

**لم يُقَس:** صفحة «اليوم» بعد الدخول (تحتاج حسابًا على الإنتاج)، وTTI.
